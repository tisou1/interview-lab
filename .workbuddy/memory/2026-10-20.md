# 2026-10-20

## 澄清：项目技术栈归属（Web ≠ React Native）

用户误以为 interview-lab 是 React Native 项目。实际确认为纯 Web 静态站点：
- 依赖中无 react-native / expo / metro / capacitor，无 android/ 与 ios/ 目录
- 构建产物 `dist/` 共 2.2 MB（最大单文件 index js 516 KB，含 CodeMirror、字体、React）
- 部署形态为 GitHub Pages 静态托管 + HashRouter，用户浏览器访问，不产出 APK

## 技术选型讨论：若要做成手机 App 的体积权衡

给出各路线 Release 包体量级对比与结论，未做代码改动：
- PWA（现状可做）：0 MB 安装，2.2 MB 缓存
- WebView 套壳（Capacitor）：约 6–8 MB（容器 + 本 dist）
- 原生 Kotlin + Compose 重写：约 6–9 MB
- React Native（Hermes）：约 13–18 MB
- Flutter：约 16–20 MB

核心结论：Android WebView 由系统提供不占包体，因此「套壳」与「原生重写」体积几乎持平，
为省体积而重写原生是亏本；原生真实收益在冷启动、推送通知（复习提醒）、系统集成。
推荐路径：PWA → 需要通知时 Capacitor + 本地通知 → 仅极致性能需求才考虑原生。
原生重写成本：需重建 176 题 Markdown 管线、CodeMirror 编辑器、6 套主题 token、
Zustand 持久化与版本迁移、间隔复习算法、图表、Playwright E2E。
