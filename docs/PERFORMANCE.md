# 性能与统计口径

## 加载策略

首页只读取题目元数据、搜索文本和本地学习状态。答案按分类动态 import，路线在进入阅读页后加载；解析工具只存在于构建阶段。React、图标、CSS 和题库全部来自本站，无字体/CDN 运行时依赖。

SVG 图表使用当前记录计算，不持久化图表副本；数据点提供键盘焦点、数值提示、摘要与表格。90 天日趋势固定至多 90 个点，现有题库无需虚拟列表。

搜索输入 200ms 防抖。Zustand 使用 selector 订阅；练习时钟的半秒显示刷新留在工作区，每 5 秒或关键操作时才写入存储。

`pnpm build` 会打印所有 JS/CSS 的 gzip 体积，并要求入口 JS 小于 180 KiB gzip。首次完整构建入口约 100 KiB gzip，CSS 约 5.5 KiB gzip；实际数字以当前构建输出为准。全部题解与路线属于额外的按需内容。

## 统计口径

| 指标         | 计算方式                                                       |
| ------------ | -------------------------------------------------------------- |
| 作答次数     | 有提交记录且 status 为 answered 或 again；允许多次练习同一道题 |
| 有效学习时间 | 上述记录的前台练习秒数之和，未提交题目暂不显示在趋势中         |
| 当前掌握率   | 当前题库中最新自评为 good 的题数 / 当前题库总数                |
| 分类掌握率   | 同一分类中 good 的题数 / 当前分类总数                          |
| 自评覆盖率   | 本场具有 mastery 的题数 / 本场题数                             |
| 面试掌握比例 | 本场 good 的题数 / 本场已自评题数，未自评不视为错误            |
| 面试总用时   | completedAt - startedAt；超时交卷使用 deadline                 |
| 平均每题用时 | 面试总用时 / 本场题数                                          |
| 待复查       | 独立 flag，可与 answered/again 重叠，不与其他状态相加          |

每日趋势使用提交时保存的本地日期，避免后来更改时区重新分配历史日期。过去记录来自场次分类快照；当前分类图随题库内容变化。未来复习计划显示接下来 7 个日历日，当前到期数量另行展示。

没有历史记录的旧导入数据，只影响当前进度图。自评不是客观正确率，不推断分数或 AI 评分。
