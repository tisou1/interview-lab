# 架构与状态边界

## 分层

- `scripts/`：构建时内容解析与校验，不进入浏览器。
- `src/data/`：只读题目索引和按分类懒加载的数据访问。
- `src/storage/`：Zustand store、localStorage 适配器、导入与迁移校验。
- `src/lib/`：抽题、筛选、复习间隔和统计等纯函数。
- `src/pages/`：路由页面，按路由动态导入。
- `src/components/`：答题工作区、SVG 图表、对话框与显示组件。

直接依赖 `react-router`，使用 HashRouter（见 [ADR 002](decisions/002-hash-routing.md)）：路由状态位于 URL fragment，静态托管无需 SPA 回退。应用负责未知路径、未知题目和缺失报告的空状态。Motion 统一提供 180–220ms 的入场与反馈动画；组件通过 useReducedMotion 在减少动态效果模式下取消动画，状态更新不依赖动画结束。

## 状态分工

URL 保存搜索、分类、难度、题型、标签、状态、排序和紧凑视图。Zustand 保存跨页面学习数据；展开章节、弹窗、临时选择保存在组件。只读题库不存入 localStorage。

持久化 key 为 `frontend-interview-lab:v1`，当前内部 schema version 为 3。存储键后缀保留，迁移由 persist envelope 的版本号管理。版本 3 把主题字段从 `light` / `dark` 改为主题 id；旧值经 `toThemeId` 归一为默认的 Vitesse 浅色或深色，因此持久化迁移与 JSON 导入共用同一条映射。

主题分层：`src/lib/themes.ts` 是主题注册表与 id 归一化的唯一来源；`src/styles/tokens.css` 按 `html[data-theme]` 声明调色板，语义变量在 `:root` 引用调色板；`Layout` 负责把当前主题同步到 `data-theme`、`.dark` 与 `meta[name=theme-color]`。样式层只消费语义变量，不写死颜色。

`QuestionProgress` 保存最新熟练度、草稿、收藏、累计时间与连续掌握次数。`StudyRecord` 保存提交时的当地日期、题目分类、用时、回答状态和自评。场次保存题目标题/分类快照、当前位置、截止时间与逐题状态。

详情页拥有按题目持久化的独立作答实例；点击「重新练习本题」产生新 record ID。练习与模拟面试分别保存一个当前场次。历史面试保留报告快照。

## 更新与幂等

每个作答实例有唯一 `recordId`；重复点击自评不产生新记录。面试交卷只执行一次；报告改评更新原记录，并按提交时间重新计算复习状态，不增加 attempts。

旧备份的进度可以作为 `ratingBase` 基线保留；不将旧进度转换成虚构的每日记录。新记录在基线上继续计算连续掌握次数。

练习时钟用 performance.now 计算实际前台时间，每 5 秒及切题、提交、离开页面时保存。页面隐藏期间不累计练习时间。面试计时使用绝对 deadline，Layout 在所有路由检查到期并自动交卷，恢复页面后再次检查；面试整体用时按开始/交卷时间计算。

## 失败恢复

存储解析失败时保留原文备份并恢复空状态；备份失败时禁止覆盖原始存储。读取或写入受限、额度不足均显示持久提示，并提供内存数据导出。

导入先检查版本、字段类型、时间、场次索引、重复记录等，再经用户确认整体替换。导出包含历史记录与当前场次。自定义草稿始终作为文本展示。

HashRouter 的直接链接只标识题目/报告；报告本身属于当前浏览器，不是公开共享链接。此版本不提供云同步或多个设备自动合并。
